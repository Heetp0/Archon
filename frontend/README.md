# Archon Frontend

React + Vite + Tailwind CSS frontend application.

## Run Development Server

```bash
cd artifacts/archon_design
pnpm install
pnpm dev
```

## Modes Available

- Dashboard Mode
- Chat Mode
- Council Debate Mode
- Deep Research Mode
- Agents Directory Mode
- Obsidian Notebook Mode
- Lecture Audio Mode
- Monitoring & Telemetry Mode (`/monitoring`)
